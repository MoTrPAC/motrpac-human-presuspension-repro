# Stage 1 (build_data) raw sources

Raw inputs for the Stage 1 QC-norm stems in `../`
that are **not** regenerated inside this pipeline — external artifacts vendored
here so the stems that consume them run offline.

## `methylcap_qc_norm/` — for `../generate_methylcap_qc_norm.R`

MethylCap-seq beta-value matrices, one file per tissue:
`human-precovid-sed-adu_{t03-edta,t06-muscle,t11-adipose}_epigen-methylcap-seq_qc-norm_beta-values_v1.2.txt`.

**Provenance:** produced by **Yongchao Ge (yongchao.ge@mssm.edu)**. MethylCap-seq
preprocessing, QC and normalization run in an external, assay-specific pipeline;
**that raw preprocessing code is not included in this repo.** These beta-value
matrices are the pipeline's *input* — the methylcap stem consumes them only for
their `feature_id`s (genomic ranges `chr:start-end`) to regenerate the v1.4
feature-metadata (gene) annotation. The matrices themselves are not modified.

**Downloaded 2026-07-27** from the production data hub:
`gs://motrpac-data-hub/analysis/human-precovid-sed-adu/c1.3/epigenomics/qc-norm/`. 
This matches the original file that Yongchao provided.
These carry consortium-gated sample/vial labels — do not redistribute outside an
approved data-access agreement.

These files exceed GitHub's 100 MB per-file limit and are gitignored. To fetch or
refresh them:

```bash
make sources GROUPS=methylcap_qc_norm
```

## `atac_qc_norm/` — for `../generate_atac_qc_norm.R`, **only when `RERUN_ATAC=FALSE`**

ATAC-seq log-cpm matrices, one file per tissue:
`human-precovid-sed-adu_{t05-pbmc,t06-muscle}_epigen-atac-seq_qc-norm_log-cpm_v1.2.txt`.

Unlike the methylcap matrices, these are **not** an external artifact — this pipeline can
and by default does produce them, by fitting voom/dream in `../generate_atac_qc_norm.R`.
They are vendored here only to support `RERUN_ATAC=FALSE` in `config/pipeline.env`, which
stages the released matrices instead of refitting so that a run can be scoped to the other
omes. On that path the stem copies these into the freeze verbatim and consumes them only
for their `feature_id`s and sample columns; the feature and sample metadata are still
regenerated by the same code the rerun path uses.

`config/copy_from_source.sh` globs on `*atac*qc-norm*.txt` — that bucket folder also holds
the methylcap beta-values.

**Downloaded from** the production data hub:
`gs://motrpac-data-hub/analysis/human-precovid-sed-adu/c1.3/epigenomics/qc-norm/`.
These carry consortium-gated sample/vial labels — do not redistribute outside an
approved data-access agreement.

A bare `make sources` skips this group unless `RERUN_ATAC=FALSE`. To fetch it explicitly:

```bash
make sources GROUPS=atac_qc_norm
```
